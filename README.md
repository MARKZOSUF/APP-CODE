# 🌌 ANIMATION SYSTEM

### 🌈 Dynamic Gradients

Color doesn't simply sit on the screen.

It can move.

```text
🟣 → 🔵 → 🟢 → 🟡 → 🔴 → 🟣
```

Animated gradients can be used across:

* Backgrounds
* Buttons
* Cards
* Headers
* Borders
* Navigation
* Loading states

---

### ✨ Glow & Light

Interactive elements can react with:

```text
Hover / Touch
      ↓
Scale
      ↓
Glow
      ↓
Light Sweep
      ↓
State Change
```

# 🧬 DESIGN PHILOSOPHY

### `01 — MOTION`

Movement communicates what is happening.

### `02 — FEEDBACK`

Every important interaction should provide visual feedback.

### `03 — DEPTH`

Layering, blur, glow and motion create a sense of depth.

### `04 — IDENTITY`

The application should have its own recognizable visual language.

### `05 — PERFORMANCE`

Effects should remain practical for real Android devices.
